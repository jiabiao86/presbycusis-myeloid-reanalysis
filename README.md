# Peripheral-central convergence of macrophage and microglial programs in presbycusis severity

Code, frozen result tables, and figure sources for a computational reanalysis of
public mouse auditory-aging transcriptomes. The study models ordinal presbycusis
severity rather than a binary hearing-loss label, compares the cochlea with the
inferior colliculus, localizes candidate genes to macrophages and microglia, and
maps cell-cell communication across the complete mouse CellChat interaction
database.

## Data sources

All input data are public and were not generated by the authors.

| Accession | Tissue or context | Platform |
| --- | --- | --- |
| GSE49543 | Mouse cochlea | Affymetrix MOE430A microarray |
| GSE49522 | Mouse inferior colliculus | Affymetrix MOE430A microarray |
| GSE233798 | Mouse cochlea (validation) | Microarray |
| GSE153882 | Mouse cochlear hair cells | RNA-seq |
| GSE154833 | Mouse cochlea (validation) | RNA-seq |
| GSE274279 | Mouse cochlea, single nuclei | 10x single-nucleus RNA-seq |

## Journal submission files

The archive contains the files prepared for submission to *Hearing Research*
(Elsevier): the manuscript with figures and tables, a figure-legend file, the
required highlights (five bullet points, each within the 85-character limit),
a graphical abstract with a 2.5:1 width-to-height ratio, and the supplementary
tables S1-S37.

## Reproducing the analysis

1. Download the GEO series listed above and place the GSE274279 matrix,
   barcode, and feature files in a local directory.
2. Run the discovery analyses: `code/R/limma_analysis.R`, then
   `code/R/wgcna_analysis.R`, then the comparison and deconvolution scripts in
   `code/python/`.
3. Run the single-nucleus localization and myeloid subclustering:
   `code/python/single_cell_localization.py` and
   `code/R/myeloid_subclustering.R`.
4. Run the sensitivity analyses: `code/R/sensitivity_analysis.R`.
5. Run the severity-focused CellChat analysis:
   `code/R/cellchat_formal_analysis.R`.
6. Rebuild and run the exhaustive CellChat database analysis:

   ```bash
   Rscript code/R/cellchat_full_cache.R 3
   Rscript code/R/cellchat_full_cache.R 12
   Rscript code/R/cellchat_full_cache.R 24
   bash code/shell/run_cellchat_full.sh          # 12 chunks, 4 concurrent
   bash code/shell/run_cellchat_full_merge.sh    # one final object per age
   Rscript code/R/cellchat_full_compare.R
   Rscript code/R/cellchat_full_analysis.R
   ```

   The chunked execution is required because CellChat dispatches a parallel job
   for every coreceptor evaluation. Each chunk is evaluated sequentially and the
   permutation seed is fixed at 1, so every chunk draws the same bootstrap
   permutations and the merged network equals a single-pass run.
7. Regenerate the figures with the `generate_*.R` scripts and rebuild the
   manuscript and submission files with the scripts in `code/python/`.

Paths inside the scripts point to the original analysis machine. Adjust the
`root` variables at the top of each script before running them elsewhere.

## Key results

- The severity model identified 181 cochlear genes at FDR < 0.05; module M12
  (66 genes) was the module most strongly correlated with severity
  (r = 0.860) and was preserved in the inferior colliculus (Zsummary = 8.40).
- 48 genes were significant in both tissues and were enriched for macrophage,
  microglial, antigen-presentation, phagocytic, and complement functions.
- Marker-based deconvolution and single-nucleus data localized the candidate
  program to macrophages/microglia rather than to hair cells, supporting cells,
  fibrocytes, or spiral ganglion neurons.
- The exhaustive CellChatDB.mouse run (2,019 interactions per age, 100
  permutations) showed contracting cochlear communication with age
  (455, 360, and 245 significant edges at 3, 12, and 24 months), a core of 46
  interactions significant at every age, PTN signaling as the strongest pathway,
  PTPRC-MRC1 myeloid self-communication at all ages, and APP-CD74 signaling that
  became significant at 12 and 24 months.
- Sex adjustment preserved the myeloid severity direction (r = 0.997 cochlea,
  r = 0.855 inferior colliculus), whereas age-group adjustment removed almost all
  significance, showing that age and hearing loss cannot be fully separated in
  this design.
- Nested cross-validation separated internal classes but did not transfer to
  GSE233798 (AUC 0.44-0.50), so machine learning is reported as a secondary
  analysis.
